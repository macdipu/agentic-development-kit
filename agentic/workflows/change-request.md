# Change Request Workflow

```text
Prompt / CR.md
 -> Normalize Work Item
 -> Load Current Baseline
 -> Identify Delta
 -> Change Impact Analysis
 -> Update/Reopen Affected Requirements and Technical Artifacts
 -> Technical Readiness when required
 -> Work Item Level Classification
 -> Sprint Handling Decision
 -> Sprint Planning only when required
 -> Epic/Stories/Tasks at minimum useful hierarchy
 -> Implementation
 -> Review
 -> Targeted / Regression QA
 -> UAT when required
 -> Release Readiness
```

A CR does not automatically require full Sprint Planning. A small CR may become Task(s) and be added to the current sprint/backlog. A large cross-module or high-risk CR may require Epic/Stories and full Sprint Planning.
