# New Feature Workflow

```text
Prompt / FEATURE.md
 -> Normalize Work Item
 -> Load Project Context
 -> Requirements
 -> SRS / UI as required
 -> Requirement Verification
 -> Architecture / Technical Preparation
 -> ADR only if needed
 -> Technical Readiness
 -> Work Item Level Classification
 -> Sprint Handling Decision
 -> Sprint Planning only when required
 -> Epic/Stories/Tasks at minimum useful hierarchy
 -> Verification
 -> Implementation
 -> Review
 -> Auto QA
 -> Manual QA
 -> UAT as required
 -> Release Readiness
```

A feature does not automatically require an Epic or full Sprint Planning. Base the decision on scope, dependencies, teams, risk, delivery complexity, current sprint state, and existing planning artifacts.
