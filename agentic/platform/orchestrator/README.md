# Orchestrator

The local runtime enforces ordered coarse-stage routes, eligible skill execution, result prerequisites, terminal state, and configured gates. The orchestrator specialist chooses work type and planning depth. The runtime does not infer requirements, invoke a model, or automatically schedule all specialists.

See the [runtime capability matrix](../../runtime/README.md#capability-matrix) and [production checklist](../agent-harness/production-readiness.md).
