# Approval Service

The local store records explicit technical, release, and optional UAT decisions against a scope revision. Ready prerequisite evidence is required for approval. Replacement evidence can revoke a gate; reopening scope invalidates old approvals. The CLI operator supplies identity text; authenticated identity and role authorization are not implemented.

See the [runtime capability matrix](../../runtime/README.md#capability-matrix) and [production checklist](../agent-harness/production-readiness.md).
