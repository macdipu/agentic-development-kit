# Tool Gateway

The local gateway checks registered capability ceilings, suppresses declared side effects in dry runs, reserves idempotency keys, and records outcomes. Unknown/failed outcomes are not automatically replayed. Handler classification, external authorization, process isolation, and external idempotency remain adapter responsibilities.

See the [runtime capability matrix](../../runtime/README.md#capability-matrix) and [production checklist](../agent-harness/production-readiness.md).
