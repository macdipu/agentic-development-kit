# Task Timing

Adapter execution records STARTED, COMPLETED, FAILED, CANCELLED, or INTERRUPTED events. Completed/failed attempts include elapsed duration; starts include retry count. CLI result ingestion measures ingestion only. Queue, tool-wait, approval-wait, and active-execution attribution are not implemented.

See the [runtime capability matrix](../../runtime/README.md#capability-matrix) and [production checklist](../agent-harness/production-readiness.md).
